# Development demo media

Original, non-branded raster assets generated for local Stage 5 content review. These files may be uploaded only through the Media Library development workflow. They are not production content and must not be copied into application source code.

- `demo-cinematic-stage.png`: wide Homepage/event/gallery image.
- `demo-production-space.png`: wide About/event/gallery image.

Resetting demo content unassigns and archives uploaded records but never permanently deletes Cloudinary assets.
